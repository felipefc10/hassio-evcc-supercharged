# evcc Supercharged

evcc with whole-house load management built in: every loadpoint is balanced under the
never-trip line of an E-REDES ICP meter by charging order, with optional supercharge bursts
above it. Everything else is stock evcc.

Source: [felipefc10/evcc, branch `supercharged`](https://github.com/felipefc10/evcc/tree/supercharged).
